한전 VR 안전교육 관제 허브

강사 한 명이 VR 실습 기기 최대 20대를 한 화면에서 보고 제어하는 관제 콘솔입니다. 외부 제작 VR 콘텐츠 20종을 하나의 런처로 통합하고, 한전이 발급한 ID로만 접속할 수 있도록 접근을 제어했습니다.

교육 현장 업무의 화면 설계

VR 실습에서는 수강생이 헤드셋을 착용하면 강사가 수강생의 화면을 확인할 수 없습니다. 최대 20명이 동시에 실습하므로 강사가 한 명씩 직접 확인하는 방식으로는 수업을 운영하기 어렵습니다. 이에 강사의 업무를 전체 기기 일괄 제어와 선택 기기 개별 제어로 구분하고, 두 기능을 하나의 콘솔에 구성했습니다.

FIG 1사용자와 시스템 구성

강사의 콘솔에서 기기로 제어 명령을 전송하고, 기기는 세션 상태와 VR 화면을 콘솔로 전송합니다. 콘텐츠는 기기별로 설치된 통합 런처가 실행합니다.

통합 런처

제작사가 서로 다른 외부 VR 콘텐츠 20종을 하나의 런처에서 동일한 방식으로 실행하도록 통합했습니다.

ID 접근 제어

한전이 발급한 ID로만 접속할 수 있도록 해, ID를 발급받지 않은 사용자의 콘솔 접근을 차단했습니다.
