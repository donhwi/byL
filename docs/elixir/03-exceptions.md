# 03. 입력 규칙 · 예외 처리

"안 됩니다"로 끝내지 않고, 왜 안 되는지와 무엇을 하면 되는지를 함께 알려 주는 것을 원칙으로 했습니다.

```
조건이 안 맞음 ──▶ 막는다 ──▶ 이유를 말한다 ──▶ 할 수 있는 다음 행동을 알려 준다
```

## 1. 입력 항목

| 화면 | 항목 | 규칙 | 어긋나면 |
|---|---|---|---|
| VISOR 추가 | 기기 고유번호 | `ELX-국가-지역코드-출고연도-일련번호` (예: `ELX-KR-11410-24-0000`) | 형식이 다르면 등록 불가 |
| VISOR 추가 | 소속 SUPERVISOR | SUPERALL은 선택, SUPERVISOR는 자기 지역으로 고정 | SUPERVISOR는 바꿀 수 없음 |
| VISOR · SUPERVISOR | NICKNAME | 24자 이하 | 넘는 글자는 입력되지 않음. 목록에서는 말줄임, 마우스를 올리면 전체 표시 |
| 고장 신고 | 유형 | 5개 중 하나 선택 (측정이 자주 실패함 / 화면이 켜지지 않음 / 결과지가 인쇄되지 않음 / 기기가 뜨거움 / 기타) | 필수 |
| 고장 신고 | 문제 내용 | 5자 이상 500자 이하 | 5자 미만이면 제출 불가 |
| 조치 계획 | 방법 | 원격 안내 / 출장 수리 / 기기 교체 중 하나 | 필수 |
| 조치 계획 | 조치 예정일 | 날짜 | 필수 |

## 2. 비즈니스 규칙과 예외

| 상황 | 처리 | 화면에서 하는 말 |
|---|---|---|
| 고유번호에 든 지역이 소속 SUPERVISOR의 지역과 다름 | 등록 불가 | 번호의 지역과 소속 지역이 다르다는 것을 안내 |
| VISOR가 남아 있는 SUPERVISOR를 해지하려 함 | 해지 불가 | 남은 VISOR 수를 알려 주고, 다른 SUPERVISOR로 옮기거나 함께 해지하도록 안내 |
| SUPERVISOR를 일시 중지함 | 소속 기기의 측정이 바로 막힘 | 영향받는 기기 수를 확인 창에서 먼저 보여 줌 |
| 측정 중에 일시정지 · 정지 · 해지가 걸림 | 진행 중인 측정은 끝까지 진행 | 확인 창에서 미리 안내 |
| 계약 종료일이 지남 | 측정 자동 차단 | 운영 상태 "계약 만료" |
| 계약 종료까지 30일 이내 | 측정 가능 | "종료 임박" 표시 |
| 측정이 실패함 | 요금을 부과하지 않음 | 기록에 실패 원인 코드를 남김 |
| 최근 7일 동안 측정 0건 | 측정 가능 | "확인이 필요한 기기"에 포함 |
| 해지 | 계정을 닫음. 로그인 불가 | 측정기록과 매출은 보관한다고 안내 |
| VISOR가 기기 상태를 정상으로 되돌림 | 진행 중인 고장 신고를 완료 처리 | — |

## 3. 측정 실패 원인 코드

측정기록에는 결과와 함께 실패 원인과 펌웨어 버전을 남깁니다. 현장 문의에 답하는 용도이면서, 어떤 조건에서 실패가 몰리는지 보고 측정 알고리즘을 고치기 위한 자료입니다.

| 코드 (예시) | 원인 | 묶음 |
|---|---|---|
| E-101 | 손 위치 이탈 | 사용자 동작 |
| E-305 | 손 움직임 | 사용자 동작 |
| E-204 | 센서 신호 약함 | 기기 |
| E-410 | 주변 빛 유입 | 설치 환경 |
| E-502 | 서버 연결 끊김 | 통신 |

```
측정 1건 = 결과(성공/실패) + 실패 원인 코드 + 펌웨어 버전 + 기기 + 시각
                                   │
                                   └─▶ 원인별 · 버전별로 묶어 보면 고칠 곳이 보인다
```

## 4. 되돌릴 수 없는 조작

해지, 일시 중지처럼 영향이 큰 조작은 실행 전에 확인 창을 한 번 거칩니다. 확인 창에는 "무엇이 바뀌는지"와 "무엇은 그대로 남는지"를 함께 적습니다.

| 조작 | 바뀌는 것 | 남는 것 |
|---|---|---|
| SUPERVISOR 일시 중지 | 소속 기기 측정 차단 | 기록, 매출, 계정 |
| VISOR 일시정지 · 정지 | 해당 기기 측정 차단 | 기록, 매출, 계정 |
| 해지 | 계정 닫힘, 측정 불가 | 기록, 매출 |
