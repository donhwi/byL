# 01. 상태값 정의

기기 한 대는 서로 다른 두 가지 상태를 함께 가집니다.
**운영 상태**는 계약과 권한의 문제이고, **기기 상태**는 기계 자체의 문제입니다. 둘을 하나로 합치면 "측정이 안 되는 이유"를 화면에서 구분할 수 없어서 축을 나눴습니다.

```
            기기 한 대
           ┌────┴────┐
       운영 상태     기기 상태
   (측정해도 되는가) (기계가 멀쩡한가)
   정상              정상
   일시정지          비정상
   정지
   해지
   계약 만료
```

## 1. 운영 상태

| 값 | 뜻 | 측정 | 누가 바꾸나 | 되돌리기 |
|---|---|---|---|---|
| 정상 | 계약 기간 안, 권한 문제 없음 | 가능 | — | — |
| 일시정지 | 잠시 막아 둔 상태 | 불가 | SUPERALL, SUPERVISOR | 바로 풀 수 있음 |
| 일시정지 (상위) | 소속 SUPERVISOR가 일시 중지되어 함께 막힘 | 불가 | 자동 | 상위 SUPERVISOR가 풀리면 함께 풀림 |
| 정지 | 운영상 이유로 막은 상태 | 불가 | SUPERALL, SUPERVISOR | 상위 계정이 풀어야 함 |
| 계약 만료 | 계약 종료일이 지남 | 불가 | 자동 | 계약을 연장하면 풀림 |
| 해지 | 계정을 닫음 | 불가 | SUPERALL, SUPERVISOR | 되돌릴 수 없음. 기록은 보관 |

### 여러 조건이 겹칠 때

한 기기에 조건이 겹치면 아래 순서에서 먼저 걸리는 것 하나만 화면에 표시합니다.

```
해지인가? ──예──▶ 해지
   │아니오
상위 SUPERVISOR가 정상이 아닌가? ──예──▶ 일시정지 (상위)
   │아니오
기기에 일시정지 · 정지가 걸려 있는가? ──예──▶ 일시정지 / 정지
   │아니오
계약 종료일이 지났는가? ──예──▶ 계약 만료
   │아니오
   ▼
  정상
```

### 계약 기간

```
계약 시작 ────────────────────┬───── 30일 ─────┬──────▶
            정상               │   종료 임박     │ 계약 만료 (측정 자동 차단)
                                                종료일
```

- 종료일까지 30일 이내로 남으면 "종료 임박"으로 표시합니다.
- 종료일이 지나면 따로 조작하지 않아도 측정이 막힙니다.
- 연장은 1년 단위입니다.

## 2. 기기 상태

| 값 | 뜻 | 누가 바꾸나 | 함께 일어나는 일 |
|---|---|---|---|
| 정상 | 기기가 정상 동작 | VISOR, 상위 계정 | 진행 중인 고장 신고가 있으면 완료 처리 |
| 비정상 | 고장이 있거나 점검이 필요함 | VISOR(직접 변경 또는 고장 신고), 상위 계정 | SUPERVISOR · SUPERALL에게 알림 |

## 3. 화면에서 묶어 보여 주는 방식

목록과 지도에서는 두 축을 다시 세 묶음으로 줄여서 색으로 보여 줍니다.

| 묶음 | 조건 | 색 |
|---|---|---|
| 고장 | 기기 상태가 비정상 | 빨강 |
| 측정 막힘 | 운영 상태가 정상이 아님 | 회색 |
| 정상 | 둘 다 정상 | 초록 |

"확인이 필요한 기기"는 고장, 측정 막힘, 그리고 최근 7일 동안 측정이 한 번도 없는 기기를 더한 수입니다.

## 4. 측정 중에 상태가 바뀌면

측정이 진행 중인 건은 끝까지 진행하고, 그다음 측정부터 막습니다. 이미 쌓인 기록과 매출은 어떤 상태가 되어도 지우지 않습니다.
