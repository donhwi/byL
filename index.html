투자봇Claude 연동 주식 거래 봇

한국투자증권 API로 국내 주식을 거래하는 웹 봇입니다. Claude가 뉴스와 공시를 조사하고, 봇이 제안한 주문은 계좌 주인이 승인해야 실행됩니다.

기간
2026.09 ~ 진행 중
구분
개인 프로젝트 · 2인 사용계좌 · 승인은 각자, 전략 · 검증 결과는 공유
사용 기술
Node · React · Claude한국투자증권 Open API (모의투자 우선)

화면운영 화면

직접 만든 운영 화면입니다 (모의투자 계좌, 2026.10.12 캡처). 화면을 누르면 다음 장으로 넘어갑니다.

트레이딩

  • 차트와 주문을 한 화면에서 확인합니다.
  • 주문 전에 손절가 제안과 청산 계획을 표시합니다.
  • 매수 · 매도 · 손절은 사람이 직접 승인합니다.

리서치 · Claude 연동

  • 서버가 조사 대상 종목을 파일로 내보냅니다.
  • PC의 Claude 예약 작업이 공시 · IR · 어닝콜 원문을 조사해 요약을 JSON 파일로 저장합니다. 뉴스는 2시간마다, 어닝콜은 매일 아침 실행합니다.
  • 서버는 Claude API 키 없이 이 파일만 읽어 표시하고, 형식이 맞지 않는 항목은 제외합니다.
  • 요약에 매수 · 매도 의견은 넣지 않습니다.

전략

  • 전략을 버전 단위로 관리합니다.
  • 전략마다 검증 여부를 표시합니다.

백테스트

  • 과거 데이터로 전략을 시험합니다. 이 화면에서는 주문이 나가지 않습니다.
  • 최근 18개월 데이터는 마지막 시험용으로 남겨 둡니다.
