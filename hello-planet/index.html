㈜알파스튜디오 · 습관 교육 앱

헬로플래닛

보호자의 핸드폰을 사용하는 미취학 아동을 위한 사용 습관 교육 앱입니다. 아이가 사용 시간을 직접 설정하고, 해당 시간 동안 보호자가 허용한 앱만 사용합니다. 약속한 시간이 종료되면 핸드폰이 잠기고 아이에게 보상이 지급됩니다.

보호자와 아이, 두 사용자 구조

이 앱은 설정하는 사용자(보호자)와 실제 사용하는 사용자(아이)가 다릅니다. 보호자에게는 안심하고 핸드폰을 건넬 수 있는지가, 아이에게는 약속을 지켰을 때 보상을 받는지가 중요합니다. 두 사용자의 사용 순서를 하나의 플로우로 정리하고, 앱이 개입하는 시점을 정의했습니다.

FIG 4보호자 · 아이 사용 플로우

기술 제약에 따른 기능 범위 조정

기획한 기능을 모든 환경에서 동일하게 구현할 수는 없었습니다. 구현 불가 항목을 먼저 확인하고, 구현 가능한 범위 안에서 기능을 재정의했습니다.

FIG 5잠금 기능: OS별 적용 범위

약속 시간 종료 시 핸드폰을 잠그는 기능은 OS 정책에 따라 구현 가능 여부가 달랐습니다. Android는 권한 접근 방식으로 구현했고, iOS는 앱에서 화면 잠금을 제어할 수 없음을 확인한 뒤 적용 범위를 조정했습니다.
