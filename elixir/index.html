엘릭서: 비침습 혈당 측정 서비스 ADMIN 기획

비침습 혈당 측정 기기를 여러 국가와 장소에 설치해 운영하려면 기기별 측정 가능 여부와 측정 불가 사유를 본사, 지역 담당자, 현장이 각자의 권한 범위에서 확인할 수 있어야 합니다. 이를 위한 ADMIN의 화면 구성, 권한, 상태값, 예외 처리를 기획했습니다.

서비스와 기기

엘릭서는 근적외선(NIR) 분광 센서로 피를 뽑지 않고 혈당을 재는 기기와 그 소프트웨어입니다. 기기는 여러 사람이 쓰는 장소에 설치되고, 이용자는 앱으로 결과를 확인합니다. 기기를 설치한 쪽은 ADMIN에서 기기와 계정을 관리합니다.

권한 구조

계정은 SUPERALL(본사), SUPERVISOR(지역), VISOR(현장) 3단계로 구성했습니다. 상위 계정이 하위 계정을 생성하며, VISOR 계정 1개는 기기 1대와 연결되므로 VISOR 계정 수가 설치 기기 수와 같습니다.

ADMIN 시안

기획서의 화면 구성을 조작 가능한 시안으로 재구성했습니다. 상단의 "로그인 계층"에서 계정을 SUPERALL, SUPERVISOR, VISOR로 전환하면 계정 단계에 따라 메뉴와 조회 범위가 달라집니다.

Elixir Admin지도의 지역을 선택하면 하위 지역으로 이동합니다 · 물음표 아이콘에 마우스를 올리면 도움말이 표시됩니다새 창에서 크게 보기

기기 이름, 위치, 측정 수, 금액은 모두 예시 데이터입니다. 실제 화면 디자인이 아니며, 기획한 화면 구조를 재구성한 것입니다.

지도 기반 탐색

전 세계, 국가, 지역, 구 단위로 범위를 좁혀 기기를 조회합니다. 측면 패널의 측정 순위는 최근 10분부터 전체 기간까지 조회 기간을 변경할 수 있습니다.

03 입력 규칙 · 예외 처리 전문

고장 신고 → 조치

현장(VISOR)이 고장을 신고하면 지역(SUPERVISOR)이 1차로 접수하고, 지역에서 해결할 수 없는 건은 본사(SUPERALL)로 이관합니다. 신고 시점에 기기 상태가 비정상으로 전환되며, 완료 처리 시 정상으로 복귀합니다.

진행 순서신고 · 이관현장에 전달되는 안내

SUPERALL이 처리하는 건도 조치 방법과 예정일이 VISOR 화면에 동일하게 표시됩니다. 도식에서는 선이 겹쳐 생략했습니다.
