AI 자동매매 검증 시스템

AI가 차트와 뉴스를 분석해 내린 매매 판단을 모의투자 환경에서 검증하는 시스템입니다. 기획부터 개발까지 전 과정을 단독으로 수행했으며, 검증이 완료되기 전에는 실계좌에 적용하지 않는 것을 원칙으로 운영하고 있습니다.

운영 플로우

15분 단위로 차트와 뉴스를 분석하고, 매매 조건에 해당할 때만 모의투자 계좌로 주문합니다. 한 세션에서 분석은 약 20회 수행되지만 실제 매수 · 매도는 평균 1.3회입니다.

검증 원칙

모의투자 환경에서 검증

한국투자증권 모의투자 API를 연동해, 실제 자금을 사용하지 않고 매매 전략을 검증합니다.

검증 완료 전 실계좌 미적용

검증이 완료되기 전에는 실계좌에 적용하지 않는 것을 원칙으로 정하고 유지하고 있습니다.

외부 제약 사전 확인

연동 대상의 제약 사항을 먼저 확인한 뒤 구현 범위를 정하는 방식으로 진행했습니다.

그 외 AI 도구

업무와 개인 용도로 필요한 도구를 직접 기획하고 제작해 운영하고 있습니다.

LLM 지식베이스

경력과 프로젝트 기록을 Obsidian 문서로 축적하고, Claude Code와 MCP로 연결해 필요한 정보를 조회하도록 구성했습니다. Jira도 MCP로 연동했습니다. 이 포트폴리오의 사실 확인에도 사용했습니다.

  • Claude Code
  • MCP
  • Obsidian
